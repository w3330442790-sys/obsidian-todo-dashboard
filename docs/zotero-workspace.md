# Zotero 式文献工作台

## 第一阶段 · 文献库和条目详情

中栏用紧凑表格呈现标题、创建者、日期、附件和期刊标签。左栏提供分类、标签及阅读状态筛选。右栏跟随选中的文献，显示条目信息、评分、笔记、摘要、附件、分区和阅读进度。窄屏可独立打开条目详情。已有阅读、翻译、摘录、编辑和引用功能从条目详情进入。

Zotero CSV、CSL JSON 和 Web API JSON 导入保留可用的日期精度和常用书目信息。相同 Zotero Key 或 DOI 的条目可在导入预览中补齐缺项。来源冲突时保留现有值。已有 PDF、阅读进度、引用键和本地笔记继续使用原来的文献记录。

## 第二阶段 · 一次连接，反复使用

- 首个入口已实现。桌面端开启 Zotero 本机 API 后，使用「从 Zotero 刷新」直接读取个人库条目及分类路径。刷新按页读取整个书目清单，对 Obsidian 只执行新增和补全，适用于当前的个人库工作流。
- 0.7.1 支持按条目取回本机 PDF。已有 PDF 的文献保留原附件，单附件直接打开，多附件可选择一份。批量复制和多个 PDF 的持久关联后续独立处理。
- 选择个人库或群组库，保存连接与库范围。先支持从 Zotero 向 Obsidian 更新。
- 按库标识、条目 Key 和版本增量读取。新增和可安全补全的字段自动处理，冲突集中查看，重复运行结果一致。
- 导入分类树、标签、条目关系、PDF 与子笔记。附件单独排队，失败可以续传，远端删除进入人工核对。
- 桌面和移动端分别验收。迁移样例用少量条目即可，日常工作走同一个刷新入口。

## 第三阶段 · 阅读与写作

- 0.7.1 并排显示原文选段和译文，摘录记录原文、译文、个人批注及 PDF 页码。原版 PDF 与译版整页同步、Zotero 高亮和批注迁移仍待实现。
- 迁移 PDF 高亮和批注定位，支持从批注生成可回链笔记、检索全文和重开阅读位置。
- 支持 CSL 引文样式、引用键管理、文中引文和参考文献表。单独验证 Word 与 LibreOffice 等写作端的连接方式。
- 支持浏览器收集与标识符建档，集中处理重复项。

## 第四阶段 · 插件能力

按工作流迁移常用插件能力。EasyScholar 分区已接入。Better BibTeX、Better Notes、PDF Translate、Journal Tags 以及自定义列与详情区分别建立验收用例。Zotero 插件依赖自己的运行时，Obsidian 端通过兼容数据、重新实现功能或与 Zotero 联动来交付。

「文献扩展」可登记 GitHub 仓库，并启停已交付的适配。Green Frog 当前交付期刊指标更新，作者和标题整理、书目刷新等工具分别评估和适配。新增仓库时记录用途、所需接口和验收样例，再为通过验收的功能提供开关。
