# 工作台 v3：紧凑首页、记录与复盘设计

日期：2026-10-27
状态：待用户确认本设计后实施；本文件不表示功能已开发或发布。

## 目标与选择

保留现有独立插件、BRAT 地址和数据格式，升级为紧凑的首页工作台。参考 Home Pages 的拖动落点、网格缩放、自动滚动等交互，自行实现与本插件文件同步约定兼容的布局。备选方案是依赖 Home Pages 的宿主 API，或只修补现有线性排序；前者增加两插件安装与数据配置依赖，后者不能满足完整拖拽体验，因此选独立升级方案。

参考：https://github.com/jepicaju862-lab/home-pages

## 顶部导航与待办合并

移除插件内左侧导航，顶部保留：首页、待办与日程、灵感与复盘、Codex 助手。设置与刷新作为顶部工具按钮。窄屏导航可横向滚动，不能挤压主内容。

待办与日程页面以列表、月历、四象限、时间轴四种视图切换，同页共享搜索、清单筛选、新建和显示已完成。列表包含今日、逾期、未安排、全部范围；分类清单转为筛选及管理入口，回收站收进更多菜单。旧命令仍能进入对应视图，旧任务 ID、重复规则、清单和专注记录保持兼容。

## 首页模块与专注合并

保留每日风景横幅、今日待办、最近笔记、自定义笔记统计及 Codex 入口，新增灵感速记与回顾复盘。首页概览保留任务、逾期、笔记指标，移除重复的“今日专注”指标；将计时与今日专注汇总合成一张紧凑“专注”卡。

专注卡默认占电脑约三分之一行，显示本次正计时、开始/暂停/继续/结束按钮，以及今日、本周和使用以来总专注时长。继续保持正计时，不新增自动休息轮次。暂停保留累计值，暂停区间不计时。已关联任务名称可见，长标题省略显示。

总专注按所有有效历史 session ID 汇总，加上当前未入库计时的有效时长；结束保存的过渡期间按 ID 去重，不能同时累加两遍。今日和本周按实际专注区间跨日拆分，包含当前进行中的有效时间。运行中状态沿用本机 localStorage，完成记录经 EasySync 同步；不支持运行中跨设备接力。历史记录仍计入累计时长，没有逐日生成新的汇总文件。

## 布局交互

现有实现仅在编辑模式下从小手柄拖至另一卡片之前，只有 6/12 两种宽度；没有空隙与末尾插入目标、拖动预览及边缘滚动。以上是已确认的能力缺口；用户电脑“完全无法拖动”的具体宿主原因尚需复现。

新版在顶部提供明显的编辑布局入口与操作提示。编辑时可从卡片标题拖动，按钮/输入框仍可交互；拖动显示浮动预览与明确插入线，支持卡片前后、行间和末尾落点，靠近滚动边缘自动滚动，Esc 或 pointercancel 取消。缩放从右下角拖动，宽度按 12 列网格吸附，显示实时尺寸；窄屏只调整高度。布局采用确定性流式网格重排，不支持把卡片悬浮叠放在其他卡片上。

保存顺序与电脑/平板独立尺寸；旧 6/12 配置可迁移。默认缩小专注卡；旧用户如保留手动布局，提供清晰的“应用新版推荐布局”入口。已有自动生成的默认布局可迁移；明确保存的自定义布局不静默清空。不能在拖动或编辑文本期间因外部文件刷新丢失输入。

## 灵感记录

首页直接输入想法、感受或灵感，点击保存后清空输入并显示最近记录。每条独立保存为 Todo工作台/灵感/<稳定ID>.md，正文保存文本，前置信息含创建时间及可选类型，兼容普通 Markdown 查看和 EasySync。列表可点开原笔记；编辑按原始快照检查冲突，失败保留输入。先提供文本和可选分类，不引入附件上传、复杂富文本或自动 AI 改写。

## 回顾复盘

首页提供今日、本周、本月及自定义日期范围，显示完成任务、逾期情况、有效专注、灵感记录及同期笔记活动概览。可以手写复盘，也可以点击“用 Codex 生成草稿”。

点击后先展示本次范围与提供给模型的材料：相关任务/专注统计、范围内灵感正文、笔记标题及路径；整篇笔记正文不默认批量读取并注入。使用已连接的 Windows Codex 只读会话生成，明确区分事实、观察与建议，引用对应文件；生成时显示状态与停止入口，不能抢占正在使用的助手对话。

AI 输出先作为可编辑草稿；用户点击保存后写入 Todo工作台/复盘/<稳定ID>.md，记录日期范围、创建时间与来源。不会自动覆盖已有复盘。失败保留手写内容和已有记录，仍可手动保存。安卓可录入灵感、查看和编辑已同步复盘；本版在安卓不能运行本机 Windows Codex，AI 生成入口说明需电脑操作。

## 验证与交付
