# 月历与手机适配

用户已要求直接升级 Todo 工作台，参考提供的紧凑月历截图。

保留七列月历、难度色、范围日期、点击编辑和每日详情。取消每天三项限制；日期头固定紧凑高度，任务标题换行，日期格内滚动呈现全部任务。默认勾选显示已完成，允许用户手动隐藏。已完成保持删除线。

修复风景署名按钮被通用 td-button 字体和内边距覆盖的问题，明确限定字体、行高、宽度、高度与边框。手机导航收紧，风景设置和署名不覆盖正文。所有改动只作用于插件宿主。

采用现有渲染与 CSS，不增加依赖，不改变任务文件格式。相比只缩小字号，此方案同时消除任务数量上限；相比改为独立日程列表，保留月历全局浏览。
