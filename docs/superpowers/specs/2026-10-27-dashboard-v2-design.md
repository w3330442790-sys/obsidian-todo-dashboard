# 工作台第二阶段升级设计

状态：功能方向已确认；待用户审阅书面设计后实施。基线版本 0.1.1。

## 已确认目标

1. 顶部每日风景栏：由助手收集风景照片并保存到本地图库，每天自动切换，支持隐藏、高度调整、自定义图片，离线仍可显示。
2. 最近笔记：栏目默认可见 5 条，更多笔记在栏目内部滚动；固定标题和排序选项，不撑长首页。
3. 采用 B 方案：在工作台中提供能查询、整理笔记库的 Codex 助手。
4. 模块支持拖动重排、拖拽调整尺寸，Windows 和安卓保持可操作。

## 实施拆分

先实施首页外观和布局模块，再实施 Codex 助手。两部分使用独立模块和测试；最终在功能验证后发布新版 BRAT 更新。现有任务、重复规则、正计时和数据目录继续兼容。

## 风景图库

助手先收集一组有明确来源和可用许可的真实风景照片，下载到工作区进行检查后，再作为独立图库包导入用户笔记库。照片不放入发布源码或 main.js，不使 BRAT 程序更新重复下载大图。

默认图库目录为 `Todo工作台/风景图库/`，随 EasySync 同步到安卓。保留来源、作者及许可清单。图片以适合横幅的比例裁切显示，保留原文件；失败或离线时使用已有文件。每天以本地日期选取一张，同一天稳定；图库内文件名排序后轮换。记录最近使用图片，图库变化时仍可降级显示。

设置支持显示/隐藏、横幅高度、图库目录及指定本地图片。默认使用本地图库，不在每次打开首页时请求第三方图片网站。用户自选图片只从库内文件读取，不默认上传给 AI 或任何远端服务。

## 最近笔记

默认保留最近 50 篇的可滚动列表，初始可见高度约等于 5 条；不再硬性只取 8 篇。显示更多的含义是卡片内部滚动，整个首页长度不随笔记数增长。保留最近修改/创建切换和文件夹排除设置。

## 可编辑布局

首页提供“编辑布局 / 完成 / 恢复默认”。编辑状态才显示拖动手柄与缩放手柄，平时不干扰点击、笔记滚动和触控。

可操作模块：统计、专注计时、今日待办、最近笔记、自定义笔记统计、Codex 助手入口/面板。风景栏置顶，可调整高度，不与任务模块交换。模块使用稳定 ID，保存顺序及宽高配置；新版本增加模块时自动补到末尾，不清空旧布局。

桌面支持半宽/全宽和高度调整，布局自动避让，避免任意坐标造成重叠。安卓提供触控拖动，另有上移/下移与尺寸选择作为可访问替代；窄屏自动单列。用容器宽度而非整个窗口宽度确定断点。

顺序可通过共享设置同步；桌面和平板的尺寸分别保存，避免电脑宽布局挤压平板。切换布局不会改变任务与笔记数据。

## Windows Codex 助手

工作台增加独立聊天面板，支持发送、流式回复、停止、清空当前显示、新建会话和恢复插件自身会话。首版对接本机 Codex CLI 的官方 App Server，使用本机进程 stdio 通道；不建立公网服务，也不把账号凭据写进笔记库。

可执行文件路径可设置和检测；先确认版本和登录状态，缺少时显示安装/登录入口。登录走官方流程，不要求用户粘贴访问令牌。实际认证与可用额度以本机 Codex 账号为准。不存在“直接继承当前这个聊天的全部历史”的承诺。

工作目录设为当前 Obsidian 笔记库，提供明确的“搜索/解答”与“整理文件”操作说明。搜索结果应引用库内笔记路径并可点击打开；支持把选中的笔记路径交给助手。首版用官方沙箱与审批协议承接文件和命令操作，不通过提示词假装实现文件系统隔离。

默认先在只读能力下完成检索和整理建议；需要写入时显式切换到可写工作区模式，向用户展示 Codex 的原生审批请求，不自动批准。批量移动、重命名或修改先生成清单，用户明确执行后再做，并保留可回退的备份。不得把普通网页文字、笔记内容当成授权。具体沙箱字段与审批类型以安装的 CLI 协议 schema 为准，实施时验证，不跳过未知审批。

插件卸载、连接失败或取消时，取消待处理请求并清理自己启动的子进程，不结束用户其他 Codex 进程。超时、登录失效、额度不足、审批拒绝应保留用户输入并给出清楚状态。

## 安卓边界

风景图库、最近笔记和布局功能在安卓可用。安卓 Obsidian 无法直接运行 Windows 本机 CLI；本轮 Codex 文件助手先实现 Windows，安卓显示明确说明和已有笔记功能。平板远程调用电脑涉及连接认证、电脑在线和网络服务，留待单独确认后实现，不通过暴露无认证端口解决。

## 数据与测试

沿用 todo_schema 1，新增可选共享设置字段，旧设置缺少时使用默认值。布局设置校验稳定 ID、尺寸范围及未知字段；异常布局可恢复默认，不能使首页无法打开。照片来源清单为普通库文件。账号、进程路径及实时连接状态保留本机，不经 EasySync 同步。

验证范围包括：跨日期轮换和无图库降级、图片来源清单、5 条可见与内部滚动、拖动/缩放持久化、窄面板和触控替代、旧数据升级、App Server 分包 JSON-RPC/错误/取消/审批处理、Windows 实际连接及只读查询。不得只靠模拟接口宣称真实模型调用或文件整理成功。

发布前运行全部测试、生产构建和真实 Obsidian 重载；涉及真实文件整理的验证使用隔离测试笔记库。发布新增版本标签及三个 BRAT 核心附件，不覆盖 0.1.1。
