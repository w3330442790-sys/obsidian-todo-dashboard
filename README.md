# 从容 · Todo 工作台

Obsidian 插件，当前测试版 0.3.1。一个插件提供首页仪表盘、待办日程、灵感复盘和课程整理，支持 Windows 与安卓界面布局。数据存储于普通库文件夹，便于 EasySync 同步。

## 安装本地测试版

1. 解压 `release/todo-dashboard-0.3.1.zip`，得到 `todo-dashboard` 文件夹。
2. 将该文件夹放到你的笔记库 `.obsidian/plugins/` 下，最终应有 `.obsidian/plugins/todo-dashboard/main.js`、`manifest.json` 和 `styles.css`。
3. 在 Obsidian 设置 → 第三方插件中关闭受限模式，刷新插件列表并启用 **Todo 工作台**。
4. 点击侧栏仪表盘按钮，或命令面板运行 **Todo 工作台：打开首页仪表盘**。重新打开 Obsidian 后默认进入首页。

电脑和平板各安装一次插件。安卓文件管理器需显示隐藏文件夹才能找到 `.obsidian`。先在测试库使用，确认后再放入日常库。

## 功能

0.3.1 默认使用紧凑首页：顶部 120px 风景与短统计条，桌面两行 5/4/3 卡片，平板按可用宽度两栏、窄屏单栏。1440px 隔离桌面测试中，首页主体底部约 855px。最近笔记默认 5 行可见，更多内容内部滚动；字体保持可读尺寸，不依靠整页缩放。

首页仅保留灵感即时输入、专注控制、任务列表和复盘/助手摘要。点击 **写复盘 / AI 复盘** 打开完整日期、材料及编辑器；点击 **打开对话** 进入完整聊天，已有草稿/会话在这些页面切换间保留，摘要入口不会自行触发模型任务。

升级时备份原模块排列、尺寸及风景设置，应用新的紧凑预设。首页 **布局与外观 → 恢复之前布局** 可还原；在旧模式中再做调整、重新切入紧凑模式时，会备份刚修改的设置。重复应用当前紧凑预设不会覆盖该备份。所有任务、专注、灵感、复盘及课程数据不变。
- 顶部导航：首页、待办与日程、灵感与复盘、课程整理、Codex 助手。待办同页切换列表/月历/四象限/时间轴，分类与回收站收拢。
- 紧凑专注卡：本次正计时、暂停/继续、今日/本周/使用以来总时长。暂停不累计，保存期间按 ID 去重，累计值由历史记录重算。
- 灵感速记：输入想法、感受或灵感，保存为普通 Markdown，正文可直接在 Obsidian 编辑。
- 回顾复盘：选日期范围、查看材料、手写或用 Codex 生成可编辑草稿，确认后保存；生成时锁定范围。
- 课程整理：读取讯飞听见已有录音稿，先确认课程，再维护该课一篇总笔记与一篇重点笔记；上传习题后持续更新，展示增删变更并确认保存。保留原始资料、来源、历史版本，检测人工修改。
- 顶部每日风景栏：9 张精选真实照片独立图库，一键下载或导入自己的照片；按本地日期轮换，离线使用本地图像。作者及许可在横幅署名和库内来源清单可查。
- 编辑布局：拖动标题重排模块，显示预览与插入线，支持末尾落点、边缘滚动和 Esc 取消；拖动右下角按 12 列缩放；也可用上移/下移和半宽/全宽操作。顺序共享，桌面和平板尺寸分别保存，可恢复默认。
- Windows Codex 助手：官方本机 CLI stdio 连接、账号默认或选择模型、流式对话、笔记路径引用、停止、新会话与原生审批。默认只读；可写模式每次请求先保存 Markdown 快照。

- 首页：今日任务、逾期数、笔记总数和近 7 天新增/修改数量；专注统计合并到专注卡。
- 最近笔记默认可见 5 条，其余在卡片内滚动（最多保留最近 50 条），切换最近创建/修改；偏好设置可排除文件夹。
- 自定义文件夹或标签统计，点击查看匹配笔记。文件夹包含子文件夹，标签精确匹配。
- 日程月历、每日任务详情、四象限、未安排日期的待办箱、分类清单和回收站。
- 任务标题、备注、日期、可选时间段、所属清单/颜色、象限、关联笔记、一层子任务。
- 清单颜色可从预设色选择或自定义。任务只有一个象限，今日待办按日期跨象限汇总。
- 每天/每周/每月重复：上一期未完成时保留并提示逾期；完成后生成完成日之后的下一个周期，不补历史任务。
- 月末按原始日期号推进，例如 1 月 31 日 → 2 月 28 日 → 3 月 31 日。
- 正计时：开始、暂停、继续、结束。任务右侧播放按钮可直接关联计时；也可开始自由专注。
- 时间轴分栏显示计划安排与实际专注区间，暂停时间不计入专注，跨午夜记录按天分配时长。
- 任务采用软删除，可在回收站恢复；不发送系统提醒。

已有自定义布局保留；若希望立即缩小专注卡，点击首页 **应用紧凑推荐布局**。这会重设模块布局，保留所有任务和记录。

## 数据与 EasySync

0.2.0 新增图库目录 `Todo工作台/风景图库/`、可写请求的 Markdown 快照 `Todo工作台/整理备份/`，都属于普通库文件，可按需纳入 EasySync。布局与风景偏好仍在 `设置.md`，兼容旧版字段。图片依据各自署名许可分发，插件代码的 MIT 许可不替代照片许可。

权威数据目录默认如下：

```text
Todo工作台/
  设置.md
  tasks/
    <任务ID>.md
  sessions/
    <专注记录ID>.md
```

每个任务、每条专注记录各自独立保存。Markdown 的 YAML 区包含 `todo_schema`、`todo_kind` 与 JSON 格式的 `todo_record`，后者为权威数据；正文是方便浏览的摘要。请在插件界面编辑任务，手动改正文不会改变任务状态。

EasySync 中将 `Todo工作台/` 和 `课程笔记/` 两个目录纳入同步，Windows 与安卓使用同一笔记库。清单、颜色、自定义统计和最近笔记偏好随目录同步。不依赖同步插件的 `data.json`。计时器运行状态只保存在本设备的 localStorage；结束后的专注记录才作为文件同步，不支持运行中跨设备接力。

文件经 EasySync 下载或外部编辑后，插件监听 Vault 文件事件自动刷新。保存时比较上次读取的文件内容，发现变化则拒绝覆盖并提示重新打开编辑。重复实例使用确定性 ID 减少重复生成；完成后中断的实例生成在重载时补齐。

同一文件在两端离线同时修改仍可能触发 EasySync 冲突，需要使用 EasySync 的冲突处理。插件不宣称自动解决所有冲突。未知格式或损坏文件不会被自动修复覆盖，首页显示检查入口。

## 计时恢复

关闭或离开应用一段时间后，恢复时暂停计时，并询问是否计入离开期间的时间。可以保持暂停、计入并继续或结束保存。无后台通知和自动休息轮次。安卓系统休眠仍需实机测试。

## 每日风景与布局

首页 → 布局与外观 → 风景与布局设置 → 下载精选风景图库。也可以把 Release 中的图库 ZIP 解压，将其中 `Todo工作台/风景图库/` 合并到库中，或用设置里的文件选择器导入自己的 JPG/PNG/WebP。原有同名照片不会被自动覆盖。不要删除 `SOURCE_LICENSES.md/json`，它们记录署名及许可。横幅上的署名入口可以打开来源清单。

默认按本地日期在本地图像之间轮换；同一天不会因为刷新随机变化。隐藏、横幅高度、图库文件夹、固定图片均可设置。Android 和 Windows 均读取库内文件，照片通过 EasySync 同步；运行插件不需要每天访问图片网站。

首页点击“编辑布局”，拖动模块标题手柄换位，拖动右下角改变宽高；“完成布局”退出。移动端可使用上移、下移、方向键和宽度下拉框，避免与页面滚动冲突。最近笔记始终最多露出约 5 条，更多内容在卡片内滚动。

## Windows Codex 笔记助手

安装官方 Codex CLI 并登录后，在工作台的 Codex 助手点击“连接 Codex”。自动查找 Windows Codex 安装目录，也可在“连接设置”填 `codex.exe` 的完整路径。需要登录时由 CLI 提供官方登录网址，密码/令牌不填入插件，也不写入库内文件。

默认只读检索，可询问“查找关于某主题的笔记并列出引用”，或“总结某笔记”。回复中的 `[[笔记路径.md]]` 可点击打开。插件拥有自己的会话历史，不会自动导入其他 ChatGPT 聊天。最近显示的消息和自有会话 ID 保存在设备 localStorage，可新建对话。

切换“整理文件（可写）”会新建独立会话。每次发送可写请求前，插件先把 Markdown 笔记保存到 `整理备份/`，并生成 manifest.json 列出原路径与备份路径；快照失败不发送操作。附件不包含在该快照内。沙箱写入工作区为当前库，原生审批请求在面板里由你处理；只读模式不提供批准写入的按钮，未知扩展权限不自动批准。

先请求整理计划，再明确要求执行。不要批准与当前整理目标不符的命令。备份文件可按 manifest 路径复制回原位置；不提供自动撤销整个 Codex 会话的承诺。大型库快照超过 30 MB 时会提示先缩小范围或手动备份。

安卓无法运行 Windows 本机 CLI，本版文件助手先在 Windows 可用。安卓仍可使用所有待办、风景和布局功能，平板远程连接电脑需后续单独实现。

## 灵感与复盘

灵感存于 `Todo工作台/灵感/<ID>.md`，复盘存于 `Todo工作台/复盘/<ID>.md`。正文为权威文本，可以在 Obsidian 中手工修改；前置信息保留日期、分类和稳定 ID。未知格式和冲突副本保留并提示，不自动覆盖。

复盘可选今日、本周、本月或自选范围。生成前可展开材料，包含任务和有效专注、范围内灵感以及笔记标题/路径；不默认注入整个库的笔记正文。生成使用独立只读 Codex 线程，不污染普通聊天；与正在运行的助手请求互斥。输出先作为草稿，手工编辑后再点击保存。安卓可手写与同步，AI 生成在 Windows 完成。

## 课程录音与习题

1. 在 **课程整理** 创建/选择课程，点击 **读取录音列表**；录音旁点击 **整理**，确认所属课程后开始。
2. 插件只读取讯飞听见已有且解锁的转写稿，按实际 app/hj 来源分流。不自动提交新转写、AI 纪要或付费任务。会员状态不代替接口读取权限。
3. 检查两篇可编辑草稿及变更清单，核对教师明确考点、习题知识点、AI 建议与待核对术语。确认后保存为该课程固定的两篇笔记。
4. 上传新增习题并确认课程，生成更新建议；已有文件按来源 ID/哈希去重。现有笔记的增删修订需要勾选已核对才可应用，不直接自动覆盖。
5. 手工改动会与上次确认版本比较并提示。需要始终保留的段落可放入 `<!-- manual:start -->` 与 `<!-- manual:end -->` 之间；该区域逐字保留。历史版本入口可预览恢复旧正文，恢复前备份当前正文，来源处理记录保持当前状态。

文件位于 `课程笔记/<稳定课程ID>/`：`课程信息.json`、`课程总笔记.md`、`重点与考点.md`、原始资料、历史版本及整理记录。课程名称在界面及 metadata 展示，不以名称作为唯一 ID。源转写和题目保持来源链接；没有时间戳或页码时不能编造。

Windows 通过本机 `xftj-transcribe` 工具接入：默认查找 `~/.codex/skills/xftj-transcribe/scripts/xftj.py`，可在讯飞连接设置指定脚本及 Python。已有官方授权可直接读取；首次点击“讯飞授权登录”打开官方页面，凭据只留本机 `~/.xftj`，不进入库或 EasySync。工具未安装时会提示，不会伪装连接成功。本插件不分发用户凭据或第三方读取工具。

习题支持 PDF、纯文本 DOCX、TXT、Markdown 和 JPG/PNG/WebP。PDF/DOCX 优先使用 Codex 附带的 Python/pypdf 与 Poppler；缺少时需本机提供对应工具。带图片的 DOCX 请先导出 PDF。PDF 含图与扫描页会渲染成图片交由 Codex 识别，保留页码；每批最多 12 张图片/含图页、12 个文件，单 PDF 最多 200 页、单文件 25 MB、合计 50 MB，较大的资料分批处理。无法提取或识别的材料会报告失败，不写入正式笔记。图像识别与知识归纳仍需核对，尤其是转写中的医学名词和题目答案。

取消生成不提交正式笔记；已经导入的原始文件可能保留，便于重试。确认后的保存阶段不提供误导性的停止按钮；保存失败会按内容快照回滚，遇到外部同时改动则保留历史备份并提示检查。安卓可打开和编辑已同步结果，录音连接、材料识别和 Codex 整理由 Windows 执行。

## BRAT 安装与发布

仓库：[w3330442790-sys/obsidian-todo-dashboard](https://github.com/w3330442790-sys/obsidian-todo-dashboard)。

在电脑和安卓平板的 BRAT 设置中选择 **Add beta plugin**，输入：

```text
w3330442790-sys/obsidian-todo-dashboard
```

选择 `0.3.1` 或最新版本，安装后在 Obsidian 第三方插件列表中启用 **Todo 工作台**。发布附件见 [Releases](https://github.com/w3330442790-sys/obsidian-todo-dashboard/releases)。

维护者发布新版本的步骤：

1. 仓库包含源码和根目录 `manifest.json`。
2. 执行 `npm test` 和 `npm run build`。
3. 创建版本标签及 Release `0.3.1`，上传 `dist/main.js`、`dist/manifest.json`、`dist/styles.css` 为独立附件。
4. 两端 BRAT → Add beta plugin，填入 `用户名/仓库名` 安装。

`manifest.json` 版本与 Release 标签保持一致。可参考 [BRAT 开发者指南](https://github.com/TfTHacker/obsidian42-brat/blob/main/BRAT-DEVELOPER-GUIDE.md)。BRAT 负责更新程序；EasySync 负责同步普通库数据。

## 开发与验证

无运行时第三方依赖。Node.js 20 或以上：

```powershell
npm test
npm run build
```

`scripts/ui-test.cjs` 为浏览器隔离测试，需通过 `PLAYWRIGHT_PATH` 指定已安装的 Playwright，并可通过 `BROWSER_PATH` 指定浏览器。它使用内存 Vault 和模拟 Obsidian API，不读取用户笔记、不连接任何云服务。截图及报告存放 `artifacts/`。

已验证：93 项自动测试、34 项隔离浏览器交互检查、生产打包；本机讯飞读取已有转写、Codex 独立只读课程 JSON 草稿、合成 PDF 正文/含图页提取与真实模型图像读取。0.1.1 已在 Windows Obsidian 1.14.5 验证重载后样式恢复；0.3.1 最终原生界面重载、真实安卓硬件、EasySync 双端传输和冲突处理仍需按 `ACCEPTANCE.md` 验收。

首版是独立待办系统，不读取或同步原 Todo清单账号。
